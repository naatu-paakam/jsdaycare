# R1 Release Scope — jsdaycare

**Goal:** Close the loop with parents — real-time communication and billing replaces phone calls and paper invoices.  
**Prerequisite:** MVP is live and stable with at least 1 month of real usage.

---

## In Scope

### 9. Parent Communication
- [ ] Direct messaging: staff ↔ parent thread per child
- [ ] Broadcast announcements (all families | by room | by child)
- [ ] Announcement types: info, closure, health alert, event
- [ ] Read receipts on broadcasts
- [ ] Daily report notification: parent notified when report is published
- [ ] Parent can react to daily report (❤️) and reply with a note
- [ ] Email notifications for new messages and daily reports
- [ ] In-app notification bell with unread count
- [ ] Parent notification preferences (email on/off, in-app on/off)

### 10. Billing & Payments
- [ ] Tuition plan setup: weekly / monthly, full-time / part-time rates
- [ ] Auto-generate invoices on schedule (configurable: 1st of month, etc.)
- [ ] Line items: tuition, registration fee, supply fee, late pickup fee
- [ ] Manual one-off invoice creation
- [ ] Online payment via Stripe (ACH + card)
- [ ] Payment confirmation notification to parent
- [ ] Late fee auto-apply (configurable days past due)
- [ ] Per-family balance view (admin + parent)
- [ ] Overdue invoice flagging
- [ ] Subsidy / scholarship tracking (mark child, adjust invoice)
- [ ] PDF receipt per payment (downloadable)
- [ ] Monthly revenue report (CSV)
- [ ] End-of-year family summary (for tax purposes)

## Enhancements to MVP Features (R1 additions)

### Attendance
- [ ] QR code check-in: parent scans unique family QR on phone camera

### Scheduling
- [ ] Schedule change request flow: parent submits → admin approves

### Forms
- [ ] Permission slip reminder: auto-nudge parents who haven't signed

### Admin Dashboard
- [ ] Revenue widget: billed this month, collected, outstanding

---

## Out of Scope for R1
- Mobile native app (iOS / Android)
- Payroll / staff pay management
- Learning curriculum tracking
- Integration with government subsidy portals

---

## Definition of Done
- All R1 feature areas functional end-to-end
- All R1 test scenarios passing (see [R1-testing.md](R1-testing.md))
- Stripe test mode validated, then switched to live keys
- At least 1 real invoice paid online by a parent
