# Feature 7 — Admin Dashboard

**Release:** MVP  
**Priority:** P1

---

## Overview
At-a-glance command center for the director/admin. Shows operational health of the daycare each day.

---

## Today's Snapshot (top of dashboard)
- Total enrolled children
- Children checked in today / expected today / absent
- Staff on duty today / expected
- Any rooms with ratio warnings

## Enrollment Summary
- Active enrollments by room
- Waitlist count
- New enrollments this month
- Withdrawals this month

## Attendance Trends
- Weekly attendance chart (simple bar chart)
- Absentee rate

## Compliance Alerts
- Children missing immunization records
- Forms awaiting signature
- Staff certifications expiring within 30 days
- Rooms currently over ratio

## Quick Actions
- Add new child
- Record an incident
- Send announcement (R1)
- Generate attendance report (CSV export)
