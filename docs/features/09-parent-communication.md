# Feature 9 — Parent Communication

**Release:** R1  
**Priority:** P0 for R1

---

## Overview
Two-way messaging between staff/admin and parents. Replaces phone tag and paper notes home.

---

## Direct Messaging
- Staff or admin sends message to a specific parent
- Parent replies from their portal
- Thread history per child
- Unread badge count

## Broadcast Announcements
- Admin sends message to: all families | specific room | specific child
- Announcement types: general info, weather closure, health alert, event
- Read receipts (who has seen it)

## Push & Email Notifications
- Notification triggers: daily report published, new message, payment due (R1 billing), absence reminder
- Parent controls notification preferences (email / in-app)

## Daily Report Delivery
- When staff marks daily report complete, parent receives notification
- Parent views report in their portal, can react with ❤️ or add a note back to teacher
