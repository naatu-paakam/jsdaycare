# Staff (Teacher/Aide) — User Guide

**Login:** teacher@jsdaycare.com / JsDaycare@2026  
**Redirects to:** /home (dashboard)

---

## Access Summary

Staff have a focused view — they see only what's needed for daily classroom work. School configuration, staff management, reporting, and paperwork are admin-only.

| Area | Staff Access |
|---|---|
| Home dashboard | ✅ View |
| Students | ✅ View profiles (Profile + Daily Activities tabs only) |
| Stories | ✅ View & write |
| Rooms | ✅ View, check in/out students, add activities |
| Calendar | ✅ View |
| Schedules | ✅ View (read-only — admin manages schedules) |
| Menus | ✅ View weekly menu |
| Settings | ❌ Admin only |
| Staff & Payroll | ❌ Admin only |
| Paperwork | ❌ Admin only |
| Reporting | ❌ Admin only |

---

## Dashboard
See today's stats (checked in, expected, absent, rooms), room ratios, compliance alerts, and upcoming birthdays — same view as admin.

---

## Students
Browse all students in the school. Click a student name to open their profile.

**Student profile — tabs visible to staff:**
- **Profile** — personal info, allergies, doctor, address (read-only)
- **Daily Activities** — full access: view feed, add new activities, edit/delete entries

**Student profile — tabs NOT visible to staff (admin/parent only):**
- Contacts, Immunizations, Documents

**Students list** — staff cannot Add Student, edit enrollment, or delete students.

---

## Rooms
Click a room card to open it.

**Inside a room — two tabs:**
- **Students** — Check In / Check Out / Mark Absent for each student
- **Feed** — all activities logged for the room today

**Staff CAN:**
- Check students in and out
- Mark a student absent
- **+ Add Activity** (logs to selected student or all checked-in students)

**Staff CANNOT:**
- Create new rooms
- Edit room settings (name, capacity, age range, ratio)
- Add students to a room

**Activity types (12):**

| Type | What to log |
|---|---|
| Food | Meal type, quantity (all/most/some/none), bottle or food |
| Nap | Started or ended (required) + optional note |
| Potty | Wet / BM / Dry / Used potty |
| Note | Free-text observation |
| Kudos | Positive shoutout (always visible to parent) |
| Meds | Medication name + dose administered |
| Health Check | Temperature, symptoms |
| Observation | Developmental area (social/motor/language/emotional) + note |
| Incident | Description, parent notified, action taken |
| Photo / Video | Upload media |
| Name to Face | Identity verification at pickup |

**Staff Only flag** — check this to hide the entry from the parent's view.

**Student-level activities:** From the student's profile → Daily Activities tab → **+ Add Activity** to log something for just that student (not the whole room).

## Schedules
View the weekly staff and student schedule grid. Staff **cannot** add or delete schedules — only admins manage scheduling.

**What you can do:**
- See your own shifts in the Staff Schedules grid
- See student class schedules
- Use the **Print** button to print the week's schedule
- Navigate between weeks with ← →

---

## Calendar
Read-only view of school holidays, special events, and operating hours. Contact your admin to add or edit events.

---

## Menus
**Weekly Menu** (read-only) — see what's being served each day of the week for Breakfast, AM Snack, Lunch, and PM Snack.

---

## Check-In (QR Code)
You can use the front desk QR code to check students in/out — same as parents. Enter your 6-digit staff PIN, select the student, and tap Check In or Check Out.

---

## School
Staff see only their own school in the top-left. No school switcher is shown (admins who manage multiple schools see a dropdown; staff do not).
